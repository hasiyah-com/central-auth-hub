## Lessons Learned (เพิ่มใน bugs-encountered.md)

- **B44**: Decision enforcement ต้องอยู่ที่ finalizer (single source of truth) — ไม่แก้ aggregator threshold
- **B45**: Force Enrollment ต้องผ่าน OTP ก่อน — กัน attacker bypass ผ่าน mfa branch
- **B46**: Browser ไม่รองรับ Passkey → Account Recovery ไม่ใช่ OTP login (รักษา phishing-resistant model)
- **B47**: risk_challenge ต้อง consume **หลัง** WebAuthn verify ผ่าน + atomic getdel (กัน race)
- **B48**: Grace Period คำนวณ runtime จาก `created_at` ห้ามเก็บ flag
