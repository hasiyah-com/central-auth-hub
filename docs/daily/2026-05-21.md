## Bug ใหม่ที่เจอ

**B33. Container reads .env from wrong worktree folder**
- อาการ: รัน `docker compose up -d` จาก main folder แต่ `hub-backend` container อ่าน `GOOGLE_REDIRECT_URI=http://localhost:8020/...` (จาก `central-auth-starter-dorm/.env`)
- สาเหตุ: ก่อนหน้านี้เคยรัน `docker compose up -d` ใน dorm worktree folder → Docker สร้าง project `central-auth-starter-dorm` → container ใช้ `.env` จาก folder นั้น เพราะ `container_name:` ใน base `docker-compose.yml` hardcoded เป็น `hub-backend` (ไม่มี suffix) → Docker attach ตัวเดิมแทนสร้างใหม่
- ผลกระทบ: OAuth login จาก `localhost:8000` ส่ง redirect_uri เป็น `localhost:8020` → callback ไป port ที่ไม่ได้รัน → ERR_CONNECTION_REFUSED
- **กฎ:** ถ้าเปลี่ยน folder ที่ start Docker → `docker compose -p <old-project> down` ก่อน แล้วค่อย `docker compose up -d --force-recreate` จาก folder ใหม่ เพื่อให้ container อ่าน `.env` ใหม่
- **Verify:** `docker exec hub-backend env | grep GOOGLE_REDIRECT` ต้องตรงกับ `.env` ใน folder ที่กำลังทำงาน

**B34. Pytest path ใน dev-routine skill ผิด**
- อาการ: `docker compose exec hub-backend pytest hub/backend/ -v` → `ERROR: file or directory not found`
- สาเหตุ: container WORKDIR = `/app` (เพราะ COPY จาก `./hub/backend` → `/app`) → path `hub/backend/` ไม่มีใน container
- **กฎ:** ใน container ใช้ `pytest .` หรือ `pytest tests/` (ยังไม่มี tests folder — Week 13+)
- ต้องอัปเดต `dev-routine/SKILL.md` และ `CLAUDE.md § TDD Workflow`
