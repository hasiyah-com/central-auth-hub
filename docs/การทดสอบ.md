# แผนการสร้าง Dataset และการทดสอบ Hybrid RBA + Passkey Trust Layer

## 1. วัตถุประสงค์

การทดลองนี้มีวัตถุประสงค์เพื่อพิสูจน์ว่า

1. การเพิ่ม Feature Engineering สามารถเพิ่มประสิทธิภาพการตรวจจับ Account Takeover (ATO) ได้หรือไม่
2. การเพิ่ม Passkey Trust Layer สามารถลด False Positive ได้หรือไม่
3. โมเดลใดเหมาะสมที่สุดสำหรับใช้งานใน Hybrid Risk-Based Authentication
4. สามารถนำผลลัพธ์ไปใช้งานจริงภายใน Identity Hub ได้หรือไม่
