## 🎯 หัวข้อที่ครอบคลุม

### 1. PKCE — RFC 7636 (7 tests)
- Verifier length 43..128
- base64url charset
- random uniqueness
- Reject too short/long → RangeError
- **RFC 7636 §4.2 Appendix B vector match** (proves correct implementation)
- Determinism

### 2. State (CSRF) — RFC 6749 §10.12 (6 tests)
- 32 hex chars
- Match passes
- Mismatch → StateError
- Missing expected → StateError
- **Different length compared via timingSafeEqual** → StateError (no crash)
- Same length differ → StateError

### 3. Config (4 tests)
- Valid config + default scope
- Trailing slash strip
- Missing clientId → HubError
- Custom scope

### 4. Webhook (6 tests)
- Valid HMAC accepts
- Bad signature rejects
- Expired timestamp rejects
- Missing headers rejects
- Bad timestamp format
- Case-insensitive headers (Express middleware style)

### 5. Integration — End-to-end with Hub (5 tests)
- Discovery loads + checks issuer/scopes/algorithms
- **JWT verifier accepts real token** (claims: aud/iss/sub/email/exp/jti)
- **JWT verifier rejects tampered signature** (via `jose`)
- **JWT verifier rejects wrong audience**
- buildAuthorizeUrl → valid URL + state + verifier
