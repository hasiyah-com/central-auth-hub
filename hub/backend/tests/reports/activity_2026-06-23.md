## Active / History split (รอบ 2)

- **active** = `logout_at IS NULL` + อยู่ใน JWT window (60 นาที) + ไม่ถูก block → "กำลังออนไลน์" ทุกระบบรวมกัน (+ `online_seconds` นับสด)
- **items** (history) = `NOT active_cond` → ออกจากระบบแล้ว / JWT หมดอายุ / ถูก block
- พอ user logout → `logout_at` ถูก set → row หลุดจาก active ไป history อัตโนมัติ (รอบ poll ถัดไป)
- UI: panel เขียว "กำลังออนไลน์ (N)" ด้านบน + ticker 1 วิ นับเวลาออนไลน์สด, ประวัติด้านล่าง
